Android phone? Mush for Android catches Reels and Shorts themselves.

Step 0Before you start

  1. Tailscale on the iPhone, with VPN On Demand turned on (Tailscale app → Settings), so the automations can reach Mush on cellular too. If Tailscale is off, an automation just shows an error and the app opens normally.
  2. Open this page in Safari, tap Share → Add to Home Screen. That is the brain.

Step 3Two automations per app

This is the Automation tab in the Shortcuts app’s bottom bar, not an action inside a shortcut (the Open App action launches an app; it doesn’t watch for one). Shortcuts → Automation → + → App. For each row: choose the app, tick only the one box shown, pick Run Immediately, turn off Notify When Run, then New Blank Automation. Add a Text action holding the name, then Run Shortcut. In Run Shortcut, tap Input (or the arrow) and pick the Text variable; it is not passed on its own. Mush Gate also needs Receive input turned on, or the app name never arrives.
